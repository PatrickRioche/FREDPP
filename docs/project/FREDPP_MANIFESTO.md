# Manifeste FREDPP

> **FREDPP n'a pas pour vocation de réinventer FRED.**
>
> **Il a pour vocation de le restaurer, de le documenter et de le rendre à nouveau utilisable dans l'écosystème logiciel contemporain.**

FREDPP préserve fidèlement l'héritage de QED et de FRED tout en utilisant les méthodes modernes de l'ingénierie logicielle : C++20, Git, intégration continue, tests automatisés et documentation vivante.

Lorsque la documentation historique et une interprétation moderne sont en désaccord, la documentation historique prévaut.

Sans documentation, un logiciel patrimonial perd sa mémoire. Sans code, il perd sa vie. FREDPP a pour ambition de préserver les deux.

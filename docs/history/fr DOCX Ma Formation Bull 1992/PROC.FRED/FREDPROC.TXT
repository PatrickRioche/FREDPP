 " Auteur : RIOCHE.P           le 22/04/92         a Trelaze
"PAGE - Editeur Pleine Page Domaine Public.
"
" Mode d'emploi de Fred PAGE :
"        Lancement        : FRED PAGE nom_de_fichier
"        Edition de texte :
" Modifier l'ecran presente en utilisant les touches de fonctions
" du clavier : suppression de ligne, insertion de caracteres, ...
" sans toutefois faire sortir la fleche (<===) de l'ecran,
"   et sans rien mettre sur la premiere ligne.
" Appuyer sur TRANSmit pour valider les modifs.
" Si on met quelque chose sur la premiere ligne,
"  les eventuelles  modifications faites dans le reste de l'ecran
"  sont ignorees.
" Sur la premiere ligne, on peut entrer une commande FRED,
" ou  .  pour passer a la page suivante, ou - pour revenir a la page precedente;
" ou \BL pour passer en mode ligne;
"        (quand on est en mode ligne, il faut faire \BP pour revenir en mode
"         page);
" ou  /  pour faire une nouvelle fois la derniere commande executee,
" ou  Q  pour abandonner FRED P,
" ou QQ  pour abandonner FRED P, quelque soit l'etat des buffers.
"
" Il existe aussi :
"
" ! <commandes_fred>  qui permet de passer en mode ligne juste le
"     temps d'execution des dites commandes.
"   (bien mettre un blanc apres le !).
"
" Si pour une raison ou pour une autre vous etes perdu, par suite d'appui
" intempestif sur une mauvaise touche de fonction, par exemple, pour vous
" remettre en selle, faites $*$brk, ou la touche de fonction adequate de
" de votre terminal; quand vous obtenez le ?, faites  B0 \B(page)
"
" Pour les textes contenant des caracteres speciaux ( code ascii de 000 a 037)
" ou des \, pour ceux dont les lignes font plus de 80 caracteres, ou dont
" certaines lignes commencent par <===, il est preferable de travailler en
" mode ligne.
"

"
" L'utilisateur ne doit pas utiliser les buffers et les registres
" composes d'une seule lettre aphanumerique.
" Le buffer x contient le nom du buffer courant. Si l'utilisateur veut
" travailler sur plusieurs buffers, pour changer de buffer courant, il
" peut faire  BXC B(nom_du_nouveau_buffer_courant)\F
"
" Il est possible de creer ses propres commandes dans son environnement de
" travail. Pour cela il suffit de creer un fichier .init sous le catalogue

"
"   EX: De creation d'un commande PL, qui recherchera "toto" a partir de

"
" Commande:
"  PL
"

# OIU — Echappement majuscule en entrée ( Option Input Upper )

> L'option OIU permet la définition du caractère d'échappement pour entrer des majuscules dans un buffer sur un terminal n'en disposant pas.

## Syntaxe

```fred
O[+|-]IU<caractère>
```

## Paramètres

| Élément | Description |
|---|---|
| `<caractère>` | Caractère utilisé par la commande ou l'option. |

## Description

L'option OIU permet la définition du caractère d'échappement pour entrer des majuscules dans un buffer sur un terminal n'en disposant pas.

## Exemples

```fred
o+iu%
b(bufo)
a
>
%majuscule
>
\F
p
Majuscule
```

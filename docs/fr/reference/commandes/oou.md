# OOU — Echappement majuscule en sortie ( Option Output Upper )

> L'option OOU permet la définition du caractère d'échappement pour imprimer des majuscules sur un terminal n'en disposant pas.

## Syntaxe

```fred
O[+|-]OU
```

## Paramètres

Aucun paramètre explicite n'est documenté.

## Description

L'option OOU permet la définition du caractère d'échappement pour imprimer des majuscules sur un terminal n'en disposant pas.

## Exemples

```fred
o+iu%
o+ou
b(bufo)
a
>
%majuscule
>
\F
p%majuscule
```

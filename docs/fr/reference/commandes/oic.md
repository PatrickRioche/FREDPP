# OIC - Définition prompt mode commande ( Option Input Cmd )

> Conversion initiale depuis DNB14A.docx. À restructurer.

```text
OIC - Définition prompt mode commande ( Option Input Cmd )
Syntaxe :
O[+|-]IC/<chaîne>/
Exemples :
o+ic/Mode CMD>/
Mode CMD>b(bufo)Mode CMD>a>Ajout ligne dans le buffer>\FMode CMD>pAjout ligne dans le bufferMode CMD>
Descriptions :
L'option OIC permet de définir la chaîne de caractères représentant le prompt du mode commande.
Options :
Valeur implicite O-IC.
```

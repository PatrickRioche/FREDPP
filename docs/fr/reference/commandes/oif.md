OIF - Avancement de ligne ( Option Input Feed )
Syntaxe :
O[+|-]IF
Exemples :
o+if
o-if
Descriptions :
L'option OIF permet de valider ou d'invalider les sauts de ligne à chaque transmit ou return.
Options :
Valeur implicite O+IF.

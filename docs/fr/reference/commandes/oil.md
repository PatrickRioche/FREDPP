# OIL — Echappement minuscule en entrée ( Option Input Lower )

> L'option OIL permet la définition du caractère d'échappement pour entrer des minuscules dans un buffer sur un terminal n'en disposant pas.

## Syntaxe

```fred
O[+|-]IL<caractère>
```

## Paramètres

| Élément | Description |
|---|---|
| `<caractère>` | Caractère utilisé par la commande ou l'option. |

## Description

L'option OIL permet la définition du caractère d'échappement pour entrer des minuscules dans un buffer sur un terminal n'en disposant pas.

## Exemples

```fred
O+IL%
B(BUFO)
A
>
M%I%N%U%S%C%U%L%E
>\F
P
Minuscule
```

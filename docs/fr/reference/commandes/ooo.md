# OOO — Impression caractère spécial octal ( Option Output Octal )

> L'option OOO permet l'impression des caractères spéciaux en octal.

## Syntaxe

```fred
O[+|-]OO
```

## Paramètres

Aucun paramètre explicite n'est documenté.

## Description

L'option OOO permet l'impression des caractères spéciaux en octal.

## Exemples

```fred
o-oo
jp/\014/<saut de page ou effacement d'écran>o+oo
```

## Options

Valeur implicite O+OO.

Aucune remarque spécifique n'est documentée.

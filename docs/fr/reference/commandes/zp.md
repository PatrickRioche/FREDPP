# ZP — Impression de buffer   ( Zap Print )

> La commande ZP imprime le contenu du buffer désigné sur le terminal .

## Syntaxe

```fred
ZP<nom de buffer>
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom de buffer>` | Nom du buffer concerné. |

## Description

La commande ZP imprime le contenu du buffer désigné sur le terminal .

## Exemples

```fred
b(buf)
1,2k(bufp)zp(bufp)Ajout  ligne de texte numero 1Ajout  ligne de texte numero 2
```

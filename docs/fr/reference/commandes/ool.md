# OOL — Echappement minuscule en sortie ( Option Output Lower )

> L'option OOL permet la définition du caractère d'échappement pour imprimer des minuscules sur un terminal n'en disposant pas.

## Syntaxe

```fred
O[+|-]OL
```

## Paramètres

Aucun paramètre explicite n'est documenté.

## Description

L'option OOL permet la définition du caractère d'échappement pour imprimer des minuscules sur un terminal n'en disposant pas.

## Exemples

```fred
O+IL%
O+OL
B(BUFO)
A
>
M%I%N%U%S%C%U%L%E
>
\F
PM%I%N%U%S%C%U%L%E
```

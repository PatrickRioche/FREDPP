# OB - Nombre page en exécution.

> Conversion initiale depuis DNB14A.docx. À restructurer.

```text
OB - Nombre page en exécution.
Syntaxe :
O[+|-]B<nombre>
Exemples :
o+b2

Descriptions :
L'option OB permet d'augmenter le nombre de pages en exécution de FRED. 
L'option O+B<nombre> rajoute le <nombre> de pages, de même que O-B<nombre> diminue le <nombre> de pages allouées.
Options :
Valeur par défaut la taille mémoire est 3 pages de 640 mots.
```

# N~ — Complément bit à bit d'une valeur d'un registre

> La commande N~ prend le complément bit à bit de la valeur du registre et retourne le résultat dans ce registre.

## Syntaxe

```fred
N<nom registre>~
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom registre>` | Nom du registre numérique. |

## Description

La commande N~ prend le complément bit à bit de la valeur du registre et retourne le résultat dans ce registre.

## Exemples

```fred
n(reg1):1
n(reg1)~    n(reg1)p
-2
```

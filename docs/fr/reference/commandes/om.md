# OM - Passage mode trace ( Option Monitor ).

> Conversion initiale depuis DNB14A.docx. À restructurer.

```text
OM - Passage mode trace ( Option Monitor ).
Syntaxe :
O[+|-]M
Exemples :
fred
a>o+ma\c\r\c\fwa *listq!l *list>\fwa *proc1,5,28 t b(0) *proc !fred *proc>BonjourBonjour\Fwa *list q!l *listBonjour!
Descriptions :
L'option OM permet de valider ou d'invalider le mode trace des commandes exécutées.
Options :
Valeur par défaut O-M.
```

# @ — Etiquette

> La commande @ permet d'assigner un nom d'étiquette de positionnement dans un buffer.

## Syntaxe

```fred
@<label>
```

fredfred## Paramètres

| Élément   | Description       |
| ----------- | ----------------- |
| `<label>` | Nom d'étiquette. |

## Description

La commande @ permet d'assigner un nom d'étiquette de positionnement dans un buffer. Cette étiquette pourra être utilisée par la commande J(label).

## Exemples

```fred
j(label)
...........
...........
...........
@(label)
```

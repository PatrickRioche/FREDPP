# NA — Affectation du numéro de la ligne courante au registre

> La commande NA affecte le numéro de la ligne courante au registre.

## Syntaxe

```fred
N<nom registre>A
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom registre>` | Nom du registre numérique. |

## Description

La commande NA affecte le numéro de la ligne courante au registre.

## Exemples

```fred
b(buf)
n(reg1)a  n(reg1)p
4
```

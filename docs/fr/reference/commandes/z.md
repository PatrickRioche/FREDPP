# Z — Commandes diverses ( Zap )

> La commande Z fait pointer sur la ligne désignée sans afficher le contenu de la ligne.

## Syntaxe

```fred
(.)Z
```

## Paramètres

| Élément | Description |
|---|---|
| `(.)` | Adresse ou plage de lignes optionnelle, selon la forme indiquée. |

## Description

La commande Z fait pointer sur la ligne désignée sans afficher le contenu de la ligne.

## Exemples

```fred
b(buf)
2zpAjout  ligne de texte numero 2
```

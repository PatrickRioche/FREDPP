# JP — ( Jump Prompt )

> La commande JP envoie le message spécifié au terminal, sans retour chariot.

## Syntaxe

```fred
JP <remarques><nl> ou JP/<remarques>/
```

## Paramètres

| Élément | Description |
|---|---|
| `<remarques>` | Message à afficher. |
| `<nl>` | Fin de ligne. |

## Description

La commande JP envoie le message spécifié au terminal, sans retour chariot.

## Exemples

```fred
jp/Envoi d'un / jp/message/
Envoi d'un message
```

## Options

Aucune option spécifique n'est documentée.

## Remarques

Aucune remarque spécifique n'est documentée.

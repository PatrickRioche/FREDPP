# JP - ( Jump Prompt ).

> Conversion initiale depuis DNB14A.docx. À restructurer.

```text
JP - ( Jump Prompt ).
Syntaxe :
JP <remarques><nl> ou JP/<remarques>/
Exemples :
jp/Envoi d'un / jp/message/
Envoi d'un message
Descriptions :
La commande JP envoie le message spécifié au terminal, sans retour chariot.
Options :

 JE - ( Jump Exit ).
Syntaxe :
JE <remarques><nl> ou JE/<remarques>/
Exemples :
o+q
JE/Erreur Numero 5/Erreur Numero 5*
Descriptions :
La commande JE imprime le message d'erreur utilisateur au terminal.
Options :
Si l'option O+Q a été préalablement validée, JE fait quitter l'éditeur.
```

# JM — ( Jump Message )

> La commande JM envoie le message spécifié au terminal, suivi d'un retour chariot.

## Syntaxe

```fred
JM <remarques><nl> ou JM/<remarques>/
```

## Paramètres

| Élément | Description |
|---|---|
| `<remarques>` | Message à afficher. |
| `<nl>` | Fin de ligne. |

## Description

La commande JM envoie le message spécifié au terminal, suivi d'un retour chariot.

## Exemples

```fred
jm Envoi d'un message
Envoi d'un message
jm/Envoi d'un/ jm/message/
Envoi d'un message
```

## Options

Aucune option spécifique n'est documentée.

## Remarques

Aucune remarque spécifique n'est documentée.

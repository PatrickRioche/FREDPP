# ND — Définition du nombre minimum de chiffres du registre

> La commande ND définit le nombre mimimum de chiffres significatifs du contenu du registre.

## Syntaxe

```fred
N<nom registre>D<nombre>
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom registre>` | Nom du registre numérique. |
| `<nombre>` | Valeur numérique. |

## Description

La commande ND définit le nombre mimimum de chiffres significatifs du contenu du registre.

## Exemples

```fred
n(reg1):7
n(reg1)d2   n(reg1)p07
```

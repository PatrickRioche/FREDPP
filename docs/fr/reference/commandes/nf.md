# NF — Définition du caractère de remplissage du registre

> La commande NF définit le caractère de remplissage du registre.

## Syntaxe

```fred
N<nom registre>F<caractère>
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom registre>` | Nom du registre numérique. |
| `<caractère>` | Caractère utilisé par la commande ou l'option. |

## Description

La commande NF définit le caractère de remplissage du registre.

## Exemples

```fred
n(reg1):7
n(reg1)d2
n(reg1)f.   n(reg1)p
.7
```

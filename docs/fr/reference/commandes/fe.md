# FE — Informations sur les modèles

> Affiche l'ensemble des modèles définis.

## Syntaxe

```fred
FE
```

## Description

La commande **FE** affiche tous les modèles définis par l'utilisateur.

La première ligne correspond au modèle le plus récemment utilisé. Les autres modèles sont ensuite affichés par ordre alphabétique.

## Exemples

```fred
fe
```

Résultat possible :

```text
/\E(term par 1)/
e(term par 1)/1$/
```

## Options

Aucune option spécifique n'est documentée.

## Compatibilité

| Implémentation | Statut |
|---|---|
| FRED historique | Compatible |
| FRED++ | Compatible si les modèles nommés sont implémentés |

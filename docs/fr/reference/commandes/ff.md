# FF — Informations sur les fichiers

> Affiche les buffers auxquels un fichier est associé.

## Syntaxe

```fred
FF
```

## Description

La commande **FF** affiche l'ensemble des buffers possédant un fichier associé.

## Exemples

```fred
ff
```

Résultat possible :

```text
b(buf) /fred/parex ?
```

## Options

Aucune option spécifique n'est documentée.

## Compatibilité

| Implémentation | Statut |
|---|---|
| FRED historique | Compatible |
| FRED++ | À valider selon la gestion des fichiers |

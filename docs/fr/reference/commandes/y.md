# Y — Pourquoi ( whY )

> La commande Y imprime la description complète de la dernière erreur .

## Syntaxe

```fred
Y
```

## Paramètres

Aucun paramètre explicite n'est documenté.

## Description

La commande Y  imprime la description complète de la dernière erreur .

## Exemples

```fred
b(buf)*dza(bufi)
/erreur/
? search failed
y
? search failed at "/erreur/"
```

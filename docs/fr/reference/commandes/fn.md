# FN — Impression d'informations sur les registres

> La commande FN imprime le nom et la valeur de tous les registres créés.

## Syntaxe

```fred
FN
```

## Paramètres

Aucun paramètre explicite n'est documenté.

## Description

La commande FN imprime le nom et la valeur de tous les registres créés.

## Exemples

```fred
fn
n(reg1):5n(reg2):10
```

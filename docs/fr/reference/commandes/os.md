OS - Définition caractère spécial ( Option Special )
Syntaxe :
O[+|-]S<caractères>
Exemples :
fo
....o+s/&d^.*$\E[ o-s+|@#<>{(   ....o+s@b(bufo) a>MAJUSCULE>\fs/@(4).*$//pMAJ
Descriptions :
L'option OS permet de valider ou d'invalider le sens spécial ou littéral de certains caractères.
Options :
Valeur implicite O+S&.
OS/ -   Séparateur de fin de substitution ( Option Substitut / )
Syntaxe :
O[+|-]S/
Exemples :
b(bufo) a
>Majuscule>\fs!ajuscule!inusculepMinuscule
Descriptions :
L'option OS/ permet de valider ou d'invalider  le séparateur de fin dans la commande S.
Options :
Valeur implicite O+S/.

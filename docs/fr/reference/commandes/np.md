# NP — Impression du contenu du registre

> La commande NP imprime le contenu du registre au terminal.

## Syntaxe

```fred
N<nom registre>P
```

## Paramètres

| Élément | Description |
|---|---|
| `<nom registre>` | Nom du registre numérique. |

## Description

La commande NP imprime le contenu du registre au terminal.

## Exemples

```fred
n(reg1):7
n(reg1)p7
```

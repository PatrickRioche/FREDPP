## Portabilité

FREDPP v0.0.3 a été compilé et testé avec succès dans les configurations suivantes :

| Plateforme | Compilateur | Résultat |
|---|---|:---:|
| Windows 11 | MSVC 19.51 | 19/19 tests |
| Debian 13 | GCC 14.2.0 | 19/19 tests |
| Debian 13 | Clang 19.1.7 | 19/19 tests |

La validation Linux a été réalisée dans une machine virtuelle Debian sous Proxmox VE, à partir d'un clone propre du dépôt GitHub et sans modification du code source.

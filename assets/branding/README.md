# Identité visuelle FREDPP

## Logo de référence

`fredpp-logo-reference.png` est le **logo graphique de référence de FREDPP**.
Il doit être utilisé dès que le contexte permet d’afficher le logo complet :
documentation, écran d’accueil, écran À propos, visuels de release et supports de projet.

## Icône dérivée

`fredpp-android-icon.png` est une **déclinaison compacte dérivée du logo de référence**.
Elle n’est pas un nouveau logo et ne remplace pas le logo de référence.
Elle est destinée aux contextes qui imposent une icône compacte : launcher Android,
raccourci d’application, badge ou autre emplacement équivalent.

Règle permanente : **logo de référence quand l’espace le permet ; icône dérivée uniquement quand une icône est nécessaire.**

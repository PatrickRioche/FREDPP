# Sprints FREDPP

Ce répertoire contient les informations de pilotage des sprints FREDPP.

## Règle

Un **sprint** n'est pas une **release**.

- `Sprint 2.xx` : chantier interne de développement ;
- `vX.Y.Z` : version réellement publiée.

Un sprint ne change donc pas automatiquement le numéro de version du logiciel.
